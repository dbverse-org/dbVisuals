# Package index

## Main Functions

Core SQL Rooms functionality

- [`launchBrowser()`](https://dbverse-org.github.io/dbVisuals/reference/launchBrowser.md)
  : Launch the dbVisuals browser
- [`stop_sqlrooms()`](https://dbverse-org.github.io/dbVisuals/reference/stop_sqlrooms.md)
  : Stop SQL Rooms Processes
- [`sqlrooms_export_table()`](https://dbverse-org.github.io/dbVisuals/reference/sqlrooms_export_table.md)
  : Export Table to SQL Rooms
- [`sqlrooms_register()`](https://dbverse-org.github.io/dbVisuals/reference/sqlrooms_register.md)
  : Register a lazy tbl or dbMatrix/dbSpatial as a VIEW in the SQL Rooms
  database
- [`dbvisuals_export_htmlwidget()`](https://dbverse-org.github.io/dbVisuals/reference/dbvisuals_export_htmlwidget.md)
  [`export_htmlwidget()`](https://dbverse-org.github.io/dbVisuals/reference/dbvisuals_export_htmlwidget.md)
  : Export a dbVisuals spec as an htmlwidget

## Linked R viewer

Mosaic views and deck.gl layers in one linked htmlwidget

- [`mosaic_gl()`](https://dbverse-org.github.io/dbVisuals/reference/mosaic_gl.md)
  : Render a linked Mosaic + deck.gl visualization
- [`mgl_spec()`](https://dbverse-org.github.io/dbVisuals/reference/mgl_spec.md)
  : Construct a top-level Mosaic spec for the viewer
- [`mgl_data()`](https://dbverse-org.github.io/dbVisuals/reference/mgl_data.md)
  : Declare a data source for a viewer spec
- [`mgl_deckgl()`](https://dbverse-org.github.io/dbVisuals/reference/mgl_deckgl.md)
  : Build a deck.gl input node for a Mosaic spec
- [`mosaic_glOutput()`](https://dbverse-org.github.io/dbVisuals/reference/mosaic_glOutput.md)
  : Shiny output binding for the Mosaic + deck.gl viewer
- [`renderMosaic_gl()`](https://dbverse-org.github.io/dbVisuals/reference/renderMosaic_gl.md)
  : Shiny render expression for the Mosaic + deck.gl viewer
